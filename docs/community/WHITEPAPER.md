## 1. What this document is

This is a plain-language overview of the Gob ($GOBB) token and community — what it is, how it works, and what (if anything) it is meant to do beyond speculative trading. It is written to be read by a new community member with no crypto background.

This document describes the project as it exists today and the intentions of the team. It is **not** a prospectus, an offer to sell securities, or a promise of future value. Nothing here should be read as financial advice, and nothing here guarantees that $GOBB will gain value, retain liquidity, or be listed anywhere. Anyone acquiring $GOBB should only ever use funds they can afford to lose.

## 2. What is Gob?

Gob escaped the basement. Gob found the internet. Somewhere along the way, Gob ended up grinding inside someone else's game for a skin that was always "one day" away — then the game disappeared. Gob didn't. So Gob started building his own thing instead: same Gob, different foundation, this time on Solana.

$GOBB launched quietly, on-chain, before any marketing or announcement — the team built the actual token structure (locked liquidity, disclosed and vested creator allocation, revoked mint authority) first, and only started telling the story after there was something real to point to.
